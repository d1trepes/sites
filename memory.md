## Дизайн-правила (для всех сайтов, с 2026-10-23)
1. Шрифты: заголовки — Unbounded, всё остальное (текст, подписи, кнопки, меню, цифры в кружках) — Onest.
2. Анимации: только плавное появление блоков при прокрутке. Никаких бесконечных и «дёргающихся» анимаций (покачивание, плавание, пульсация, сдвиги картинок при наведении, заливка кнопки от курсора).
3. Картинки: без подложки и не на первом экране — убрать; налезает на текст или обрезается краем — убрать; никаких свечений и цветных пятен за картинками.
4. Акцентный цвет — экономно: кнопки, иконки, одно ключевое слово в заголовке первого экрана, цифры в акциях. Заливка акцентом — только у финального блока «Как записаться». Все карточки, карточка рейтинга, аватарки и плашка демо — нейтральные.
5. Переносы: заголовки text-wrap: balance, абзацы text-wrap: pretty; без одного слова на последней строке.
6. Карточки в ряду одной высоты. Заголовки карточек одного размера, короткие (2–3 слова, на компе в одну строку), порядок иконка → заголовок → текст на одной высоте у всех (на телефоне min-height у заголовка, если какой-то переносится).
7. Факты не повторяются в разных блоках.
По блокам:
- Первый экран: заголовок ≤56px на компе, 34px на телефоне, максимум 3 строки; картинка статичная без свечения; часы — мелко в шапке рядом с «Позвонить» на компе, на телефоне только в контактах. Остаются: заголовок, короткий подзаголовок, «Позвонить», «Как проехать», рейтинг.
- Блок преимуществ сразу после первого экрана — без заголовка, только ряд нейтральных карточек.
- Услуги: сетка; баннер «Сколько стоит» — только текст и кнопка, без картинки.
- Акции: нейтральные карточки, акцентом только цифры; «Уточняйте актуальность по телефону» — мелкой подписью под карточками.
- Отзывы: на компе карточка рейтинга слева залипает (sticky, отступ под шапку), на телефоне обычный порядок.
- Почему выбирают нас: только иконки, без 3D-картинок; повторы с блоком преимуществ убрать; меньше 3 карточек — блок убрать целиком. Никогда: Wi-Fi, парковка, «можно с собакой», зона ожидания.
- Как записаться: акцентная панель, картинка с инструментами целиком внутри панели (на светлой подложке), на телефоне картинку прячем; кнопка белая.
