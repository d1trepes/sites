# Библиотека картинок (blank/img/)

3D-объекты без фона. Для нового сайта копируем нужные в ПАПКА/img/ и перекрашиваем под цвет сервиса.

## Салатовые — перекрашиваются в любой цвет
`python3 tools/recolor.py "#ЦВЕТ" ПАПКА/img blank/img/ИМЯ.webp` (для чистого красного лучше `python3 tools/recolor-red.py ПАПКА/img blank/img/ИМЯ.webp`)

| Файл | Что на картинке | Куда подходит |
|---|---|---|
| hero-car.webp | ⛔ НЕ ИСПОЛЬЗОВАТЬ: низкое качество, похожа на BMW — заменить новой генерацией | — |
| svc-engine.webp | поршень и шестерня ГРМ | услуги: двигатель |
| svc-chassis.webp | амортизатор со ступицей | услуги: ходовая, подвеска |
| svc-diag.webp | диагностический сканер | услуги: диагностика, электрика |
| fact-discs.webp | тормозной диск с суппортом | тормоза, шины |
| fact-hatch.webp | хэтчбек | «с какими авто» |
| fact-bike.webp | мотоцикл | мототехника |
| fact-card.webp | банковская карта | оплата |
| cta-tools.webp | ящик с инструментами | финальный блок «Записаться» |

## Нужна новая картинка
Claude даёт Ивану промпт: «3D-рендер [объект], [цвет акцента] детали, на чистом белом фоне, студийный свет, без людей и логотипов марок, квадрат». Иван присылает картинку как есть — фон Claude вырезает сам (`pip install "rembg[cpu]"`, модель isnet-general-use), сохраняет в ПАПКА/img/ в .webp и **кладёт копию в blank/img/** с понятным именем + строку в эту таблицу.
