# Блоки бланка (для анкеты anketa.json)

Сайт = общий бланк (blank/) + анкета сервиса (ПАПКА/anketa.json). Примеры анкет: gtgarage (тёмная, цены группами), cts-service (светлая, услуги плитками), avtozveno (услуги списком, акции, цветная панель записи), avtoservismaster (жёлтый, фото, логотип-картинка).
Собрать: `node tools/build.js ПАПКА`. Обложка для ссылки: `node tools/og.js ПАПКА` (первый раз `cd tools && npm install`), потом снова build.
`"off": true` у блока, карточки или пункта — не показывать (данные остаются). `"_note"` — заметка для себя, на сайт не идёт.

## Общие поля
- name, phone, phoneLabel ("A1"), phones: [{phone, label}] — доп. номера, address ("Минск, ул. …"), city, viber, telegram, payment ("Наличными и картой")
- logo: {text, accent: "часть цветом", color: "accent"} (значков возле логотипа не ставим) или {img: "img/logo.png"}
- style: "классика" | "мастерская" | "чистый" | "плакат" — вид сайта (см. «Стили» ниже); без поля — классика
- theme: "тёмная" | "светлая"; accent: цвет вывески; onAccent: текст на кнопках (#fff; для жёлтого/салатового тёмный); accentText: акцентный текст, если accent плохо читается на фоне
- colors: {bg, bg2, card, card2, line, tx, mut} — свои оттенки фона (необязательно)
- hours: [["Пн–Пт","9:00–19:00"],["Сб–Вс","выходной"]]; schedule: [{d:[1,2,3,4,5], from:9, to:19}] — «Сейчас открыто» (1 = пн)
- yandex: {url, slug, id, rating: "4,9", marks, reviews} — без url/id карта строится по адресу
- seo: {title, description, ogTitle, ogDescription}; demo: true; legal: {company, unp, regInfo, email}
- blocks: [ … ] сверху вниз. У любого блока: title, menu (пункт меню, "" — не показывать), id

## Блоки (type)
| type | Что это | Поля |
|---|---|---|
| hero | Первый экран (обязателен) | dots: false — без точек в углах (стиль «плакат»), decor: true — сетка на фоне справа (стиль «плакат»), badge: "address" — адрес плашкой вместо строки, title (≤3 строк), badge: {icon?, t} — плашка-изюминка над заголовком, accent (слово), accentStyle: "mark" (маркер — для светлых цветов), lead, img, imgAlt, shape: "circle" (цветной круг за картинкой — только для круглых: колесо, диск), imgSize: "s" (узкая высокая) / "m" (квадратная) / "w" (широкая — машина) |
| services | Услуги | style: "side" (картинка сбоку), "tiles" (сверху), "list" (иконка+название); cols: 2/3; button: "Узнать цену"; items: [{title, img?, chips: [], wide?, full?}] (для list: [{icon, title, wide?}]); highlight: {label?, items: [{icon?, t, text?}]}; banner: {title, text, price? ("от 90" → крупно по центру), button?} |
| prices | Цены | groups: [{g, items: [[услуга, цена, пояснение?]]}] + note — или items: [{t, price, note?}] + note («Остальное — по телефону») |
| reviews | Рейтинг + отзывы | items: [{name, date, stars, text}] — пересказ; *слово* — жирным |
| why | Почему мы | brands?: {text, img?, label?}, items: [{icon, t, text}] — минимум 3 карточки (или brands + 2) |
| cards | **Свободный блок** | title? (без него — полоса карточек под первым экраном), items: [{icon?, t, text}] (2–4; одна карточка не показывается) |
| marquee | Бегущая строка (марки, техника) — без подписи сверху | items: ["BMW", "Honda", …] |
| promo | Акции | items: [{big: "−50%", t, text}] |
| photos | Фото сервиса | items: [{img, caption, alt}] |
| beforeafter | До/после с ползунком | items: [{before, after, caption}] |
| steps | Как записаться | items: [{t, d}] (3 шага); style: "panel" + img — цветная панель |
| contacts | Контакты и карта | entry? («Вход слева от вывески», как доехать) |
| cta | Финальный цветной призыв | title?, img, button? (вторая кнопка всегда «Построить маршрут») |

Иконки: shield, clock, time, wrench, car, card, doc, form, truck, check, tag, bolt, phone, camera, eye, drop, gears, search, crash, body, bumper, paint, sills, polish, anticor, weld, towbar, seat, arrow.
Картинки: blank/КАРТИНКИ.md.

## Кнопки
- Без номера телефона и без иконок. Номер — только текстом (контакты, крупно в cta).
- Основная кнопка — короткий глагол под смысл блока, поле `button` у блока: первый экран «Позвонить», цены «Записаться» / «Узнать цену», услуги «Узнать цену», плашка «Узнать стоимость», шаги «Записаться», cta «Позвонить». Можно своё (2 слова), если подходит лучше.
- Вторая кнопка — только про дорогу: «Как проехать» / «Построить маршрут». Второй номер телефона кнопкой не делаем — он в контактах.

## Каким должен быть сайт
- 7+ блоков. Типичный порядок: hero → полоса cards (3 факта) → services → prices или banner → reviews → why / promo / photos → steps → contacts → cta.
- Сборщик сам пишет ⚠ (мало блоков, одинокая карточка, длинный заголовок, пустые плитки) — каждое ⚠ исправить до отправки.
- Не хватает данных на 7 блоков — не выдумывать, а записать в notes.md, что спросить у владельца (фото, цены, гарантия, марки).

## Стили
| style | Вид | Кому подходит | Порядок блоков |
|---|---|---|---|
| классика | шрифт Unbounded, мягкие карточки, картинка справа | универсальный | hero → cards → services → prices → reviews → why → steps → contacts → cta |
| мастерская | узкий шрифт прописными, острые углы, сетка на фоне, заголовок на всю ширину (компактный), акцент — подчёркивание слова | много цен, двигатели/КПП, «мужской» сервис; лучше всего широкая машина hero-suv (imgSize "w") | hero → cards → prices → services (list) → photos → reviews → steps → contacts → cta |
| чистый | ⛔ НЕ ИСПОЛЬЗОВАТЬ (Ивану не нравится). Спокойный шрифт Manrope, текст слева, картинка справа на мягком свечении цвета (без рамок), рейтинг капсулой, плоские карточки с тонкой линией, без теней | светлая тема, аккуратный сервис, мало цен | hero → cards → services (tiles) → reviews → prices → why → steps → contacts → cta |
| плакат | первый экран целиком в цвете сервиса с кольцами и точками, крупный шрифт, акцент — подчёркивание, спокойные карточки, отступ после первого экрана | яркий цвет вывески, кузовной, шиномонтаж, акции | hero → services → promo / banner → reviews → why → photos → contacts → cta |
Шрифты стиля подключает сборщик сам. Адрес над заголовком показывается в «мастерской» и «плакате», если его нет в lead.

## Изюминка и повторы
- Изюминка — одна вещь из данных, которой сервис отличается (специализация, редкая услуга, цена, часы). На первый экран: в заголовок или badge. В других блоках не повторять.
- Сборщик пишет ⚠ «повтор внутри сайта» (5 слов подряд в двух блоках) и «как на сайте X» (6 слов подряд с другого сайта). Адрес, часы и цены не считаются. Каждый ⚠ — переписать своими словами.

## Как выбрать блок
1. Сначала — существующие блоки и их варианты.
2. «Заголовок + несколько пунктов» (эвакуатор, страховые, гарантия, оплата) — **cards**.
3. Новый блок — только для новой формы (калькулятор, таблица сравнения, видео). Тогда: «Советую новый блок X — сделай в чате БЛОК».

## Новый блок (чат БЛОК)
Функция в blank/render.js (BLOCKS), стили в конце blank/blank.css, строка в таблице выше, поведение (если нужно) в blank/site.js. Потом `node tools/build.js --all` и проверка, что ни один сайт не сломался.

## Общие правила вида (с 25.10)
- Подписей-пояснений под заголовками и блоками нет (поле sub и note у акций не выводятся). Заметка с кнопкой у цен (note) — остаётся.
- Акцент цветом — только у того, что «цепляет» или нажимается: слово в заголовке первого экрана, кнопки, значки, финальный блок записи. Заголовки остальных блоков всегда белые/обычные (*слово* в них выводится без цвета).
- Полосок над заголовками нет. Номера (01, 02) — только в шагах «Как записаться».
- Скругление кнопок = скругление карточек сайта (задаётся стилем).
