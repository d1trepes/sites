# Блоки бланка (для анкеты anketa.json)

Сайт = общий бланк (blank/) + анкета сервиса (ПАПКА/anketa.json).
Пример полной анкеты: gtgarage/anketa.json. Собрать: `node tools/build.js ПАПКА`.

## Общие поля анкеты
- name, phone, address ("Минск, ул. …"), city, viber, telegram
- logo: {text, accent: "часть названия цветом"} или {img: "photos/logo.png"}
- theme: "тёмная" | "светлая"; accent: "#E10600" (цвет вывески); onAccent: цвет текста на кнопках (#ffffff, для жёлтого #111111); accentText: цвет акцентного текста, если accent плохо читается на фоне
- hours: [["Пн–Пт","9:00–19:00"], …] — как показывать; schedule: [{d:[1,2,3,4,5], from:9, to:19}] — для «Сейчас открыто» (1 = пн)
- yandex: {url, slug, id, rating: "5,0", marks, reviews} — карта, рейтинг, ссылки
- seo: {title, description, ogTitle, ogDescription} — title и description: название, услуги, улица, город
- demo: true (плашка демо + noindex), legal: {company, unp, regInfo, email} — при запуске
- blocks: [ … ] — блоки сверху вниз. Порядок = порядок на сайте. `"off": true` — временно скрыть. `"title"` — свой заголовок, `"menu"` — пункт меню.

## Блоки (type)
| type | Что это | Поля |
|---|---|---|
| hero | Первый экран (обязателен) | title (≤3 строк), accent (слово цветом), lead, img (3D-объект), imgAlt |
| prices | Цены группами | groups: [{g, items: [[услуга, цена, пояснение?]]}], note, sub |
| services | Услуги карточками с метками | items: [{title (2–3 слова), img?, chips: [..]}] |
| reviews | Рейтинг Яндекса + отзывы | items: [{name, date, stars, text — пересказ}] |
| why | «Почему мы» | brands?: {text, img?, label?}, items: [{icon, t, text}] — минимум 3 карточки или brands |
| cards | **Свободный блок**: заголовок + 1–4 карточки | title, sub?, items: [{icon?, t, text}] |
| steps | Как записаться, 3 шага | items: [{t, d}] |
| contacts | Адрес, телефон, часы, карта | addressNote? (например «вход слева от вывески») |
| cta | Финальный цветной призыв | title?, img (инструменты) |

Иконки (icon): shield, clock, time, wrench, car, card, doc, truck, check, tag, bolt, phone.

## Как выбрать блок
1. Сначала — существующие блоки.
2. Всё, что «заголовок + несколько пунктов» (эвакуатор, страховые, гарантия, оплата, с какими авто) — блок **cards**.
3. Новый блок нужен, только если нужна новая форма: ползунок «до/после», галерея фото, калькулятор, таблица. Тогда в ответе: «Советую новый блок X — сделай в чате БЛОК».

## Новый блок (чат БЛОК)
Функция в blank/render.js (BLOCKS), стили в конце blank/blank.css, строка в таблице выше. Потом `node tools/build.js --all` — все сайты пересобираются, проверь, что ни один не сломался.
