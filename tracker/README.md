# Трекер студии — демо

Статическая демо-версия трекера для GitHub Pages: https://d1trepes.github.io/sites/tracker/

- Без сервера, базы и пароля. Данные хранятся в браузере (localStorage), у каждого устройства свои.
- Работают «Сегодня» и «Задачи» → «Неделя», остальные разделы — заглушки. «Сбросить демо-данные» — в меню.
- На iPhone: Safari → «Поделиться» → «На экран „Домой“».
- Сборка не нужна: обычные файлы `index.html`, `app.js`, `style.css`, все пути относительные.

Основная версия с базой — репозиторий `d1trepes/studio-tracker`. Отсюда скопированы стили (`style.css` = `app/globals.css`) и логика дат и быстрого ввода (`dates.js`, `parse.js` = `lib/dates.js`, `lib/parse.js`).
